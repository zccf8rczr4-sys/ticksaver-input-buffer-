# TickSaver

Buffer de inputs predictivo para Geometry Dash.

Cada vez que apretás o soltás, un jugador fantasma invisible simula el futuro. Si tu input te mataría pero unos ticks más tarde sobrevivís, el input se retiene y se entrega en el tick seguro. Funciona con cubo, bola, UFO, wave, robot, araña, swing y nave, con orbes, pads y portales.

- **F6**: activar / desactivar
- **F7**: cambiar el máximo de ticks (2 / 4 / 8 / 16 / 24 / 32 / 40)
- **F8**: modo adaptativo: los ticks se ajustan solos según lo que necesitás
- Todo se configura en los ajustes del mod.

Motor basado en Afterflow por prsevend (MIT).

**Es un cheat:** no lo uses en récords, listas ni nada que quieras presentar como legítimo.
